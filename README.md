# Book QA Engine

Система для индексации книг, гибридного поиска и ответов на вопросы на основе текста.  
Поддерживает форматы **txt, pdf, epub, fb2**.  
Использует **FAISS** для семантического поиска, **BM25** для лексического и **Ollama с Qwen 2.5** для генеративных ответов.

## 🛠 Стек технологий

- **Python 3.10+**
- **FAISS** – векторный индекс
- **sentence-transformers** – эмбеддинги (`intfloat/multilingual-e5-large`)
- **Ollama** – локальный запуск LLM (модель `qwen2.5:7b`)
- **PyPDF2, ebooklib, BeautifulSoup4** – парсеры книг
- **transformers** – extractive QA (опционально)
- **numpy, tqdm, chardet** – вспомогательные библиотеки

## 🚀 Как запустить сервис

### 1. Клонируйте репозиторий 
    ```bash
    git clone https://github.com/salijaleksandr21-bit/Strelka.git
    cd Strelka
    ```
### 2. Создайте и активируйте виртуальное окружение (рекомендуется)
    ```bash
    python -m venv venv
    source venv/bin/activate        # Linux/macOS
    venv\Scripts\activate           # Windows
```
### 3. Установите Python-зависимости
    ```bash
    pip install -r requirements.txt
```
### 4. Установите и запустите Ollama
    Скачайте Ollama и запустите сервер в отдельном окне терминала:
        ```bash
        ollama serve
```
    Загрузите модель для генерации:
        ```bash
        ollama pull qwen2.5:7b
```
### 5. (Необязательно) Настройте токен Hugging Face
    Для ускорения загрузки моделей можно добавить токен:
        ```bash
        export HF_TOKEN="ваш_токен"   # Linux/macOS
        set HF_TOKEN=ваш_токен        # Windows
        Токен получается на huggingface.co/settings/tokens.
```

📚 Как загрузить тексты книг

Запустите приложение:

bash
python manage_books.py
В главном меню выберите 3. Добавить книгу из файла.
Укажите название и путь к книге. Поддерживаются форматы .txt, .pdf, .epub, .fb2.

При добавлении можно задать параметры нарезки:

Размер чанка – количество символов в одном фрагменте (рекомендуется 700–1000)
Перекрытие – сколько символов перекрывается между соседними чанками (рекомендуется 100–200)
После добавления система автоматически построит векторный индекс и сохранит его в папку data/books/.

⚙️ Настройки

В меню настроек (главное меню → 6 или меню работы с книгой → 3) можно изменить:

K – количество фрагментов, используемых в контексте (рекомендуется 15–20)
Alpha – баланс между семантическим (эмбеддинги) и лексическим (BM25) поиском:

0 = только BM25 (хорошо для имён, точных терминов)
1 = только эмбеддинги (лучше для смысловых запросов)
Temperature – «творчество» генерации (0 = строго по тексту, 1 = свободный ответ)
Max контекст – максимальное количество токенов, передаваемое в LLM (по умолчанию 8000)

❗ Возможные проблемы

ModuleNotFoundError: No module named 'src.processing'

Убедитесь, что структура папок сохранена: src/processing/ и src/indexing/ существуют. Если нет – скачайте репозиторий заново.

AssertionError при поиске

Размерность эмбеддингов не совпадает с индексом. Удалите книгу (пункт 5) и добавьте заново – индекс перестроится.

Ошибка подключения к Ollama

Убедитесь, что ollama serve запущен и модель qwen2.5:7b загружена. Проверьте доступность:

bash
curl http://localhost:11434/api/tags
Книга не добавляется / ответы не генерируются

Проверьте, что файл книги не повреждён. Для FB2 можно открыть в браузере – внутри должен быть текст в тегах <body>.
Попробуйте уменьшить размер чанка (например, 500) или увеличить перекрытие (100–150).
Убедитесь, что в папке data/books/ после добавления появилась папка с индексом и файлами.
Предупреждения о неаутентифицированных запросах к Hugging Face

Не критично, но для ускорения установите HF_TOKEN, как описано выше.

💡 Примечания

Все модели работают локально – данные не покидают ваш компьютер.
Для больших книг (>500 страниц) может потребоваться 8–16 ГБ оперативной памяти.
Первый запуск занимает больше времени из‑за загрузки моделей (около 2–3 ГБ).
